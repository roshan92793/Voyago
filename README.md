# 🌍 Voyago

### Explore. Plan. Experience.

Voyago is a full-stack tourism and travel planning platform that helps users discover destinations, plan trips, create personalized itineraries, manage travel budgets, save destinations, and share reviews.

## 🚀 Features

- 🔐 User Registration & Login
- 🏞️ Explore Tourist Destinations
- 🔎 Search Destinations
- ❤️ Wishlist
- 🧳 Create & Manage Trips
- 📅 Day-wise Itinerary Planner
- 💰 Travel Budget Tracker
- ⭐ Reviews & Ratings
- 🗺️ Interactive Maps
- 🌤️ Weather Information
- 👨‍💼 Admin Dashboard

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript

- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
